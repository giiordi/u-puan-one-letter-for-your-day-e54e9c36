One letter for the day: **K**.

The letter stands for the word *knackered* — a day that left you utterly
spent, flat on the sofa, done in. It is vivid and specific (you can see
the collapse), funny the moment you hear it, and true to a real day.
K is its sharp, unobvious initial: not the generic A-for-amazing pick,
but the letter that fits the word's sound and shape.

The program writes exactly that one letter to `/output/entry.txt` —
one character, no word, no gloss, no punctuation, no trailing newline.
